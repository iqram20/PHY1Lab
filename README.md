## General student expectations

1. Read the assigned experiment and pre-lab questions before class.
2. Wear appropriate PPE; secure rotating/moving equipment and keep fingers away from moving parts.
3. Record original measurements, units, instrument resolution and uncertainties—not just calculated results.
4. Include labeled graphs, sample calculations, answers to analysis questions, and discussion of systematic/random error where required.
5. Compare with accepted or theoretical values only when appropriate; do not invent measurements.

## Disclaimer
